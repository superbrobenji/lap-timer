# Plan 5.6 — Dev-kit as Primary Dev Interface — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The lap-timer pushes a 1 Hz STATUS record on its existing `0xFF` stream and the dev-kit stops polling it; the dev-kit gains a USB console (REPL, `--json`, link trace, stream stats, native self-tests, a bridge to the lap-timer console, cmd-OTA flashing over USB) plus a host CLI, so all dev work runs through the dev-kit over one USB cable with no AP; the RJ45/5 V connector contract is documented for Plan 6.

**Architecture:** Lap-timer side: `status_build()` factored out of `op_status`, pushed from `link_task` every 1 s and on detect-assert as `LT_REC_STATUS` (0x40) through `stream_push()`. Dev-kit side: a pure `linkstats` module (counters, gaps, ages, STATUS cache) fed by the stream consumer; `linkhost_status()` reads the cache, never UART1. A new `console` component (`esp_console` on UART0) and a `flashcore` component (staging + push state machine extracted from `webapi.c`) sit beside `webapi` as front-ends over the same `linkhost`/`logstore`/`flashcore` core. `tools/devkit.py` drives the console in `--json` mode.

**Tech Stack:** ESP-IDF v5.3.2 (`esp_console`, `driver/uart`, `esp_timer`, `esp_partition`, mbedtls SHA-256), C11, Unity/ctest host harnesses (lap-timer `test/`, dev-kit `devcontroller/test/`), Python 3 + pyserial for the CLI.

**Spec:** `docs/superpowers/specs/2026-09-23-devkit-primary-interface-design.md`

## Global Constraints

- Build/flash only via `source tools/idf-env.sh` (must print `ESP-IDF v5.3.2`); lap-timer envs via `./build.sh <moto_sim|moto_neo6m> <build|flash …>`; dev-kit via `cd devcontroller && idf.py build`. Never flash a board without the user's "ready" (they hold BOOT).
- Lap-timer tree (`components/`, `main/`) is STRICT Power-of-10: `python3 tools/lint/power_of_10.py --enforce-fnptr --fail-on-violation` must report 0; no new function pointers; `-Werror`; `LT_ASSERT_*` never abort on target; **DRAM-neutral** (record free DRAM before/after at the 5.6.1 gate; ~432 B free today).
- Dev-kit tree (`devcontroller/`) is pragmatic Power-of-10: bounded loops with explicit caps, ≥ 2 assertions in functions over ~20 code lines, no heap in pure modules; pure host-testable code lives in `components/<c>/host/*.c` and includes only IDF-free headers (`app/lt_proto.h`, the component's own `include/`), never `esp_*`/`driver/*`/httpd.
- Shared contract lives in `components/app/include/app/lt_proto.h` (IDF-free, included by dev-kit pure code). New constants: `LT_REC_STATUS = 0x40`, `LT_STATUS_REC_LEN = 21` (type byte + 20 B STATUS).
- Timing constants: `LINK_STATUS_PERIOD_MS = 1000` (lap-timer push cadence), `LINK_STATUS_STALE_MS = 3000` (dev-kit staleness → `connected:false`).
- Self-test pass thresholds: `link` median < 100 ms, max < 500 ms, 0 failures (N = 20); `stream` fused ≥ 8/s, status ≥ 0.8/s, 0 seq gaps over 10 s; `framing` every `---BEGIN`/`---END` marker followed by exactly one CR before LF.
- Console: `esp_console` on the dev-kit's UART0 (`CONFIG_ESP_CONSOLE_UART_NUM` = 0, 115200); every command accepts a trailing `--json` and then prints exactly one JSON object per line (NDJSON for `tap`/`trace`); the bridge escape is `~.` at line start, hard cap 10 min.
- USB flash staging handshake (mirrors the lap-timer's `ota recv`): `flash stage <size> <sha256hex>` → `STAGE-READY` → `<size>` raw bytes → `STAGE-END 0x0000` | `STAGE-ERR <badsize|badsha|timeout|write>`; raw read in 4096-byte chunks, 3000 ms per-read stall timeout.
- `/api/flash` behaviour is preserved byte-for-byte through the `flashcore` extraction (same status codes, JSON, `flash_err` mapping).
- Physical contract (documented, not built here — Plan 6): RJ45 over straight-through Ethernet; pins 1 LT_TX, 2 LT_RX, 3 LT_EN, 6 LT_GPIO0, 4 5V_DK, 5 GND, 7 GND, 8 DETECT; 5V_DK from a DETECT-enabled boost ≥ 500 mA; never plug into real Ethernet/PoE.
- Session tags `p5.6-d1`..`p5.6-d4`, then `plan-5.6-done`. SDD ledger: `.superpowers/sdd/2026-09-23-plan-5.6-devkit-interface/progress.md`.

```c
/* Builds the §18.2 STATUS record. Shared by the framed `status` reply (op_status) and the
 * 1 Hz stream push (link.c, Plan 5.6) so the two can never drift. */
void status_build(uint8_t out[LT_STATUS_LEN])
{
    LT_ASSERT_VOID(out != NULL, CMD_ASSERT_CODE);
    memset(out, 0, LT_STATUS_LEN);
    out[LT_ST_OFF_PROTO] = 1;
    out[LT_ST_OFF_STATE] = 0;                              /* device state machine lands later */
    put_u16le(&out[LT_ST_OFF_FLAGS], (uint16_t)(sys_flags_get() & 0xFFFFu));
    out[LT_ST_OFF_BATT_PCT] = 0;                           /* power lands in Plan 6 */
    put_u16le(&out[LT_ST_OFF_BATT_MV], 0);
    put_u32le(&out[LT_ST_OFF_FREE_KB], storage_free_kb());
    put_u16le(&out[LT_ST_OFF_SESS], session_count());
    fw_short((char *)&out[LT_ST_OFF_FW], 7);
}

static int op_status(cmd_emit_fn emit, void *ctx, uint8_t tag, uint16_t *seq)
{
    LT_ASSERT_RET(emit != NULL, CMD_ASSERT_CODE, -1);
    LT_ASSERT_RET(seq != NULL, CMD_ASSERT_CODE, -1);
    uint8_t st[LT_STATUS_LEN];
    status_build(st);
    return emit_bytes(emit, ctx, tag, seq, st, sizeof st, true);
}
```

```c
/* Plan 5.6 §4.1: push a STATUS record every LINK_STATUS_PERIOD_MS while a peer is present, and
 * immediately on the absent->present edge so a freshly plugged dev-kit gets status at once. */
static void link_push_status_if_due(void)
{
    bool present = link_peer_present();
    uint32_t now_ms = (uint32_t)(esp_timer_get_time() / 1000);
    bool edge = present && !s_prev_present;
    s_prev_present = present;
    if (!present) return;
    if (!edge && (uint32_t)(now_ms - s_last_status_ms) < LINK_STATUS_PERIOD_MS) return;
    s_last_status_ms = now_ms;
    uint8_t rec[LT_STATUS_REC_LEN];
    rec[0] = LT_REC_STATUS;
    status_build(&rec[1]);
    stream_push(rec, sizeof rec);                          /* drop-on-full / M1-held: next tick resends */
}
```

```c
#include "linkstats.h"
#include <assert.h>
#include <string.h>
static linkstats_t s;
static uint16_t s_last_seq; static bool s_seq_valid;
void linkstats_reset(void) { memset(&s, 0, sizeof s); s_last_seq = 0; s_seq_valid = false; }
void linkstats_on_record(const lt_stream_rec_t *r, int64_t now_us)
{
    assert(r != NULL); assert(now_us >= 0);
    if (s_seq_valid && (uint16_t)(r->seq - s_last_seq) != 1u) s.gaps++;
    s_last_seq = r->seq; s_seq_valid = true;
    switch (r->type) {
    case LT_SES_T_FUSED: s.n_fused++;  s.last_fused_us = now_us; break;
    case LT_SES_T_EVENT: s.n_event++;  s.last_event_us = now_us; break;
    case LT_REC_STATUS:
        s.n_status++; s.last_status_us = now_us;
        if (r->len >= LT_STATUS_LEN) { memcpy(s.status_rec, r->data, LT_STATUS_LEN); s.status_valid = true; }
        break;
    default: s.n_other++; break;
    }
}
void linkstats_snapshot(linkstats_t *out) { assert(out != NULL); *out = s; }
int64_t linkstats_age_ms(int64_t last_us, int64_t now_us)
{
    if (last_us == 0) return -1;
    int64_t d = (now_us - last_us) / 1000;
    return d < 0 ? 0 : d;
}
bool linkstats_status_fresh(int64_t now_us, uint32_t stale_ms, lt_status_t *out)
{
    assert(out != NULL);
    if (!s.status_valid) return false;
    int64_t age = linkstats_age_ms(s.last_status_us, now_us);
    if (age < 0 || age >= (int64_t)stale_ms) return false;
    return linkhost_status_decode(s.status_rec, out);
}
```
