# Dev Controller (sub-project B) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the dev controller — a second classic-ESP32 firmware (`devcontroller/`) that drives the lap-timer's shipped serial console over UART1 and serves a browser tool (over its own WiFi AP) to configure/tune, offload sessions, live-monitor + black-box-log, and flash the lap-timer.

**Architecture:** Static SPA + REST-over-cmd bridge. `esp_http_server` serves vanilla SPA assets from a read-only LittleFS partition plus a JSON API; each endpoint bridges to `linkhost` (the UART1 client that speaks the lap-timer's `export_serial` console — framed `---BEGIN/END---` responses, the `0xFF` live stream, `ota recv`). Long-lived handlers (SSE, flash, download) run async on a worker task. A `logstore` persists the demuxed stream to flash. Three small additive lap-timer-side changes make the human console robust for a machine peer.

**Tech Stack:** ESP-IDF v5.3.2, C11, `esp_http_server`, `esp_wifi` (SoftAP), `joltwallet/littlefs`, vendored `jsmn`. Host tests via the existing Unity/ctest harness. No blocking P10 linter for B (pragmatic P10-inspired; tests + review gate).

**Spec:** `docs/superpowers/specs/2026-09-20-dev-controller-B-design.md`

## Global Constraints

- **B lives in `devcontroller/`** — a sibling ESP-IDF project at the repo root, its own `main` + `components`. It `EXTRA_COMPONENT_DIRS`-references the lap-timer's `components/app` for the shared protocol header (`app/lt_proto.h`) and vendored `jsmn`.
- **B versions independently:** `git describe --tags --match "dc-v*" --dirty --always` → `CFG_DC_VERSION`. Session tags for this plan use prefix `p5.5-d*`.
- **B link is on UART1** (GPIO tx/rx chosen in Task 2). UART0 stays for B's own console/flashing.
- **Pragmatic P10-inspired:** B's own logic (linkhost parser/demux/state machines, logstore) uses bounded loops with explicit caps, ≥2 assertions in functions >20 code lines, small focused modules. Dynamic allocation allowed in the WiFi/httpd layer. **No blocking P10 linter for B**; the gate is host tests + review.
- **Reuse the shipped console protocol** (spec §5); the only lap-timer edits are the three approved additive changes in Task 1 (shared header, stream length-prefix, config-set-if-needed).
- **Baud 115200** on the link (matches the lap-timer console). One request in flight at a time.
- **Flash budget (4 MB):** partitions `nvs` / `phy_init` / `factory` (~1.5 M) / `www` LittleFS RO (~256 K) / `ota_stage` raw (~1.25 M) / `logs` LittleFS RW (~0.9–1 M ≈ 20–25 min capture). Log rotation keeps the newest.
- **Lap-timer builds must stay green** for the Task 1 edits: `source tools/idf-env.sh` (prints v5.3.2), `./build.sh moto_neo6m build && ./build.sh moto_sim build` rc=0, `test_apps/core_selftest` links, `python3 tools/lint/power_of_10.py --enforce-fnptr --fail-on-violation` = 0, host tests green.
- **Do NOT flash** any board without the user's "ready" (they hold BOOT). On-target verification steps are flash gates run by the orchestrator with the user present.

## Task 3: `linkhost` core — framed request/response + length-aware demux + stream ring

**Files:**
- Modify: `devcontroller/components/linkhost/linkhost.c`, `.../include/linkhost.h`
- Test: `devcontroller/test/test_linkhost_frame.c`, `devcontroller/test/test_linkhost_demux.c`

**Interfaces:**
- Produces:
  - `typedef struct { char name[16]; uint32_t size; const uint8_t *body; size_t body_len; } linkhost_frame_t;` (body points into linkhost's static assembly buffer, valid until the next call).
  - `int linkhost_cmd(const char *cmd, linkhost_frame_t *out);` — send `<cmd>\r`, read the framed response, base64-decode if the format is binary, verify the CRC over the decoded body, fill `*out`. Returns 0, or `LINKHOST_E_TIMEOUT`/`_NOTCONN`/`_CRC`/`_PROTO`.
  - `int linkhost_stream_pop(lt_stream_rec_t *out);` — pop one demuxed stream record (`{uint16_t seq; uint8_t flags; uint8_t type; uint8_t len; uint8_t data[LT_REC_MAX];}`), 0 if one was returned, <0 if empty.
  - Internal (host-testable, non-static or exposed via a test header): `size_t linkhost_feed(const uint8_t *bytes, size_t n)` — the demux state machine: consumes raw UART bytes, routes framed-response bytes to the response assembler and `0xFF` frames to the stream ring, skips echo/prompt/`ESP_LOG`/`ERR`/boot-log noise.

```c
    TEST_ASSERT_EQUAL_UINT(13, f.size);
    TEST_ASSERT_EQUAL_INT(0, memcmp(f.body, "{\"proto\":1}\n", 12) == 0 ? 0 : 1);
}
```
