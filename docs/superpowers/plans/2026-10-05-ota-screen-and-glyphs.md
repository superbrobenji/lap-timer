# OTA Progress Screen + SIM/MOVING Header Glyphs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show the spec's `UPDATING` one-shot (bar + percentage + a status line) while an OTA image is being received, verified and applied; show the spec's `UPDATE FAILED / REVERTED` one-shot after a bootloader rollback; and add two header glyphs — `SIM` (permanent on a sim build) and `MOVING` (shown whenever the menu is motion-locked, gone once parked) — so a bench operator can see when a sim run has finished and the lap-timer accepts input again.

**Architecture:** Pure first, wiring second. Task 1 changes only `components/core/ui` (host-tested, golden-compared on both canvases): a status line on the OTA one-shot driven by a new `ota_phase` model field, two 12×12 icons, and two ui-level bits (14, 15) in the existing fault-icon strip. Task 2 wires the firmware: a new ui-only event `EV_OTA` (posted straight to `g_ui_evt_q`, never via `emit_event()`, exactly like `EV_CFG_CHANGED`) from `ota.c` and the supervisor's rollback detection, and the ui's handling (enter/update/leave the one-shot, ignore buttons while it is up, fold the two glyph bits into the strip mask).

**Tech Stack:** ESP-IDF v5.3.2 (`source tools/idf-env.sh`), C (C11, Power-of-10 lint), host harness via CMake/CTest + Unity (`cmake -S test -B test/build && cmake --build test/build -j && ctest --test-dir test/build`), PBM goldens under `test/snapshots/` and `test/snapshots/213/`.

**Spec:** `docs/superpowers/specs/2026-09-14-lap-timer-design.md` — §19.4 (OTA apply/validate/rollback: "shows UPDATE FAILED, REVERTED for 3 s"), §20.5 (fault-icon strip), §20.6 (one-shot screens: `OTA` (progress bar), `UPDATE FAILED, REVERTED`), §20.7 (menu lock above `MENU_LOCK_SPEED_KMH`: "a lock-icon flash" — realised here as the persistent `MOVING` glyph). The approved in-chat design (2026-10-05) is restated in the two task introductions below; the spec sections are amended by the tasks that change behaviour.

### Task 2: Firmware wiring — EV_OTA from ota.c/supervisor, ui handling, strip bits

**Design restated:** `ota.c` (runs on the console task inside `ota recv`) posts a ui-only `EV_OTA` straight to `g_ui_evt_q`: `RECEIVING 0 %` on a successful `ota_begin`, `RECEIVING n %` whenever `n / 5` changes during `ota_data`, `VERIFYING 100 %` when `ota_end` starts the signature check, `REBOOTING 100 %` when it succeeds (the supervisor reboots `OTA_REBOOT_DELAY_S` = 2 s later), `ABORTED` on every failure path. The supervisor posts `ROLLED_BACK` from `ota_boot_decide()` when the bootloader reverted an image. The ui enters `ONESHOT_OTA` on the first non-terminal phase (a screen replacement → full refresh), updates `ota_pct`/`ota_phase` in place (partials), ignores every button while the OTA one-shot is up, returns to riding on `ABORTED`, and shows `ONESHOT_OTA_FAIL` for 3 s right after the BOOT one-shot when a rollback was flagged. `update_flags()` masks the sys snapshot to 14 bits and ORs in `SCR_UI_SIM` (compile-time) and `SCR_UI_MOVING` (`s_gspeed_kmh >= MENU_LOCK_SPEED_KMH`, the exact test `ui_open_menu()` uses).

```c
static uint8_t s_ui_pct_step;          /* last pct/5 step posted to the ui (throttle, ota_ui_post) */

/* Tell the ui (ui-only EV_OTA, never emit_event(): not logged, not streamed -- same contract as
 * EV_CFG_CHANGED). Non-blocking: a full ui queue drops the update, the next one catches up. */
static void ota_ui_post(uint8_t phase, uint8_t pct)
{
    LT_ASSERT_VOID(pct <= 100u, OTA_ASSERT_CODE);
    if (g_ui_evt_q == NULL) return;    /* ui not started (recovery mode) */
```

```c
/* EV_OTA (ui-only). Non-terminal phases show/update the persistent OTA one-shot (no auto-revert:
 * the supervisor reboots 2 s after REBOOTING; ABORTED returns to riding). ROLLED_BACK at boot is
 * deferred until the BOOT one-shot expires, then OTA_FAIL shows for ONESHOT_OTAFAIL_MS. */
static void handle_ota(const event_t *e)
{
    LT_ASSERT_VOID(e != NULL, UI_APP_ASSERT_CODE);
    LT_ASSERT_VOID(s_model.screen <= SCR_ONESHOT, UI_APP_ASSERT_CODE);
    uint8_t phase = e->flags;
    uint8_t pct   = e->arg16 > 100u ? 100u : (uint8_t)e->arg16;
    if (phase == EV_OTA_ROLLED_BACK) { s_rollback_pending = true; return; }
    bool on_ota = s_model.screen == SCR_ONESHOT && s_model.oneshot == ONESHOT_OTA;
    if (phase == EV_OTA_ABORTED) {
        if (on_ota) ui_exit_menu();       /* -> SCR_RIDING, full refresh (ruling B-9) */
        return;
    }
    s_model.ota_pct   = pct;
    s_model.ota_phase = phase;
    if (!on_ota) {
        s_model.screen     = SCR_ONESHOT;
        s_model.oneshot    = ONESHOT_OTA;
        s_oneshot_until_us = 0;           /* persistent: no auto-revert */
        s_wants_full       = true;
        s_screen_changed   = true;        /* whole-screen replacement (ruling B-9) */
    }
    s_dirty = true;
}
```
